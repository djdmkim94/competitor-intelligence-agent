## ChatGPT Competitors (Consumer AI Chat)

> **Report audience**: Product Marketing Managers (PMMs)
> **Focus**: Messaging, positioning, user sentiment, retention, consumer adoption

### Anthropic — Claude
- **Products**: Claude.ai (consumer chat), Claude Apps (iOS/Android with live charts/diagrams), Claude Pro ($20/mo), Claude Max, Claude for Enterprise, Cowork (persistent agent threads), Claude computer use (Dispatch)
- **Latest models**: Claude Opus 4.6, Claude Sonnet 4.6, Claude Haiku 4.5; **Claude Mythos** leaked (described as "step change" in capabilities, unprecedented cybersecurity risks per draft materials)
- **Positioning**: AI safety + full productivity platform. 14+ launches in March 2026 alone. Shifting from assistant → always-on agent.
- **Strengths**: 1M context (Opus), strong developer trust, growing consumer base, Claude Code dominance in coding, IPO planned as early as October 2026
- **Weaknesses**: Smaller user base than ChatGPT, less brand recognition, 5 outages in March 2026 (reliability concern)
- **Key people**: Dario Amodei (CEO), Daniela Amodei (President), Mike Krieger (CPO, ex-Instagram)
- **Twitter**: @AnthropicAI, @DarioAmodei, @mikeyk, @bcherny
- **Threat level**: HIGH — massive March launch cadence, IPO plans signal long-term independence, Mythos leak suggests next-gen model imminent

### Google — Gemini
- **Products**: Gemini (consumer chat), Gemini Advanced, AI Overviews (Search), NotebookLM, Google TV AI, Gemini in Workspace (Docs/Sheets/Slides/Drive)
- **Latest models**: Gemini 3.1 Pro (#1 on 12/18 benchmarks), Gemini 3 Flash, Gemini 3 Flash Lite ($0.25/$1.50 — fastest model)
- **Positioning**: AI integrated across Google ecosystem. **March "Gemini Drop"**: chat history migration from other providers (directly targeting ChatGPT users), Personal Intelligence now free for all US users, Lyria 3 Pro music gen (3 min tracks), Gemini Live 2x context.
- **Strengths**: Billions of Google users, **ChatGPT-to-Gemini migration tool** (direct retention attack), strong multimodal, 1M context, deep Workspace integration
- **Weaknesses**: Consumer engagement still lower than distribution suggests
- **Key people**: Demis Hassabis, Sundar Pichai, Jeff Dean
- **Twitter**: @GoogleDeepMind, @demishassabis
- **Threat level**: HIGH — migration tool is a direct retention attack on ChatGPT

### xAI — Grok
- **Products**: Grok (chatbot on X/Twitter), SuperGrok subscription, Grok Imagine (image + video generation), Grok API
- **Latest models**: Grok 4.20 Beta 2 (March 3 — better instruction following, fewer hallucinations), 2M context, leading agentic index
- **Positioning**: "Unfiltered" AI deeply integrated into X/Twitter algorithm. Video generation expansion to compete with Sora.
- **Strengths**: $20B Series E closed (investors: Founders Fund, Fidelity, NVIDIA, Cisco), X/Twitter distribution, aggressive scaling, 2M context, video gen (Grok Imagine)
- **Weaknesses**: Nearly all original co-founders departed (2025-2026), niche positioning, dependency on X platform
- **Key people**: Elon Musk; Nikita Bier (head of product, X — announced Grok will power X's algorithm)
- **Twitter**: @xai, @elonmusk
- **Threat level**: MEDIUM-HIGH — $20B funding + X algorithm integration could significantly expand reach beyond niche

### Perplexity
- **Products**: Perplexity Search (free), Perplexity Pro ($20/mo), **Personal Computer** (always-on Mac mini AI agent), **Comet** (enterprise assistant for in-page research + autonomous tasks), **API Platform** (Agent API, Search API, Embeddings API, Sandbox API coming), Market Research agent (Pro/Max pilot)
- **Positioning**: Evolved far beyond search — now a full AI platform with agent capabilities, enterprise products, and hardware. Direct ChatGPT competitor across search, research, and autonomous task execution.
- **Strengths**: Clean UX, source citations, fast-growing power user base, premium data partnerships (CB Insights, PitchBook, Statista), full API platform for developers, hardware play (Personal Computer)
- **Weaknesses**: Copyright/publisher tensions (NYT lawsuit ongoing), Amazon shopping bot legal battles, hardware bet is risky
- **Key people**: Aravind Srinivas (CEO), Denis Yarats (CTO)
- **Twitter**: @perplexity_ai, @AravSrinivas, @denisyarats
- **Threat level**: HIGH — no longer just search. Full AI platform with agents, enterprise, APIs, and hardware competing directly with ChatGPT's core use cases

## Codex Competitors (AI Coding Tools)

> **Report audience**: Product Managers (PMs)
> **Focus**: Feature launches, benchmarks, enterprise adoption, developer sentiment

### Cursor / Anysphere
- **Products**: Cursor (AI-native code editor), Cursor for Business, **Automations** (autonomous cloud agents, launched March 5), **Graphite** (code review tool, acquired)
- **Models used**: Claude, GPT-4o, custom models
- **Positioning**: Evolved from "smart editor" to **platform for autonomous cloud agents**. $29.3B valuation (March 2026, up from ~$10B). 60% revenue from enterprise.
- **Strengths**: $2.3B funding round (Accel, Coatue, Thrive, Google, NVIDIA), enterprise clients include OpenAI/Uber/Spotify/Shopify/MLB, autonomous cloud agents, Graphite acquisition adds code review
- **Weaknesses**: Dependent on third-party models, no proprietary model moat, Automations feature still early
- **Key people**: Michael Truell (CEO), Sualeh Asif (CPO), Aman Sanger (COO). Note: Arvid Lunnemark departed Oct 2025 (founded Integrous Research)
- **Twitter**: @cursor_ai, @mntruell, @amanrsanger, @sualehasif996
- **Threat level**: HIGH — $29.3B valuation, autonomous agents platform, enterprise dominance

### Anthropic — Claude Code
- **Products**: Claude Code (CLI agent), Claude Code in IDE (VS Code, JetBrains)
- **Positioning**: Agentic coding — Claude operates autonomously in your terminal/codebase, not just autocomplete
- **Strengths**: SWE-Bench leading (Sonnet 4.6 ~55%), terminal integration, project memory, strong real-world coding
- **Weaknesses**: CLI-first UX less accessible than IDE-native tools, newer product
- **Twitter**: @AnthropicAI
- **Threat level**: HIGH — best benchmarks, agentic approach is differentiated

### Google — Gemini Code Assist + Jules
- **Products**: Gemini Code Assist (IDE plugin, now **free for individual devs** with Gemini 2.5 Pro), Jules (autonomous coding agent, **out of public beta**, powered by Gemini 3 Pro), Gemini CLI
- **Latest models**: Gemini 3 Pro (surpasses 2.5 Pro at coding, agentic workflows + complex zero-shot tasks)
- **Positioning**: Enterprise coding at Google scale. Free individual tier + tiered Jules subscriptions (Pro: 5x limits, Ultra: 20x limits).
- **Strengths**: Free Gemini Code Assist for individuals, Jules GA with Gemini 3 Pro, IDE + Cloud Workstations integration, Google Cloud enterprise pipeline
- **Weaknesses**: Jules still catching up to Cursor/Claude Code in developer mindshare
- **Threat level**: HIGH — free tier + Jules GA with Gemini 3 Pro is most aggressive coding tools play

### GitHub Copilot (Microsoft/OpenAI-adjacent)
- **Products**: Copilot Individual, Copilot Business, Copilot Enterprise, Copilot Workspace
- **Positioning**: The incumbent. First-mover in AI coding, deepest GitHub integration.
- **Strengths**: Largest installed base, GitHub integration moat, Copilot Workspace for agentic workflows
- **Weaknesses**: Powered by OpenAI models (not really a "competitor" but a partner-competitor), perceived as falling behind on coding quality
- **Threat level**: MEDIUM — incumbent with massive distribution but losing mindshare to Cursor/Claude Code

### Cognition (Devin + Windsurf)
- **Products**: Devin (autonomous AI software engineer), Windsurf (AI-native IDE, formerly Codeium), Windsurf for Enterprise
- **Positioning**: Full-spectrum AI coding — from copilot (Windsurf) to autonomous agent (Devin). Acquired Windsurf July 2025 after bidding war (Google DeepMind, OpenAI both competed). Now 200+ employees (up from 40 pre-acquisition).
- **Strengths**: Only company spanning both copilot and autonomous agent; $10B+ valuation ($400M round led by Founders Fund); Devin embedded directly into Windsurf IDE; enterprise features across both products
- **Weaknesses**: Products still largely separate as of March 2026 (integration incomplete); smaller player vs. Cursor ($29.3B) and Claude Code; competing on multiple fronts simultaneously
- **Key people**: Scott Wu (CEO)
- **Twitter**: @cognition_labs, @scottswu
- **Threat level**: HIGH — the combined Devin + Windsurf portfolio makes Cognition the most comprehensive AI coding competitor
