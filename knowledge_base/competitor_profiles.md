## Tier 1 — Core Competitors (Deep weekly analysis)

### Anthropic (Claude)
- **Founded**: 2021 | **HQ**: San Francisco
- **Key products**: Claude (consumer chat), Claude Code (coding assistant), Claude API, Claude for Enterprise
- **Latest models**: Claude Opus 4.6, Claude Sonnet 4.6, Claude Haiku 4.5
- **Positioning**: AI safety + enterprise reliability. Increasingly pushing into consumer with "workspace" framing (Projects, persistent memory)
- **Strengths**: Long context (200K tokens), strong coding benchmarks (SWE-Bench), developer trust, growing enterprise pipeline via AWS Bedrock
- **Weaknesses**: Smaller consumer user base than ChatGPT, less brand recognition, limited multimodal (no image generation)
- **Key people to monitor**: Dario Amodei (CEO), Daniela Amodei (President), Claude Code product leads
- **Twitter accounts**: @AnthropicAI, @DarioAmodei
- **Career page**: careers.anthropic.com
- **Threat level to OpenAI**: HIGH across all product lines

### Google DeepMind (Gemini)
- **Founded**: 2010 (DeepMind) / merged with Google Brain 2023 | **HQ**: London + Mountain View
- **Key products**: Gemini (consumer chat), Gemini Code Assist, Gemini API, AI Overviews (Search), NotebookLM
- **Latest models**: Gemini 2.5 Pro, Gemini 2.5 Flash
- **Positioning**: AI integrated across Google's ecosystem (Search, Workspace, Cloud, Android). Distribution advantage is their moat.
- **Strengths**: Massive distribution (billions of Google users), strong multimodal, competitive pricing, Cloud partnerships, research depth
- **Weaknesses**: Brand confusion (Bard → Gemini), enterprise trust still building, consumer product feels secondary to Search integration
- **Key people to monitor**: Demis Hassabis (CEO DeepMind), Sundar Pichai, Jeff Dean
- **Twitter accounts**: @GoogleDeepMind, @demaborsa
- **Career page**: careers.google.com (filter: Gemini)
- **Threat level to OpenAI**: HIGH — strongest distribution advantage

### xAI (Grok)
- **Founded**: 2023 | **HQ**: Bay Area
- **Key products**: Grok (chatbot on X/Twitter), Grok API
- **Latest models**: Grok 3, Grok 3 Mini
- **Positioning**: "Unfiltered" AI, deeply integrated with X/Twitter. Targeting users who feel constrained by ChatGPT/Claude safety guardrails.
- **Strengths**: X/Twitter distribution, aggressive scaling (Colossus supercomputer), Elon Musk's reach, fast iteration
- **Weaknesses**: Niche positioning limits enterprise appeal, dependency on X platform, smaller developer ecosystem
- **Key people to monitor**: Elon Musk, xAI engineering team
- **Twitter accounts**: @xaborsa, @elonmusk
- **Career page**: xAI careers (check x.ai)
- **Threat level to OpenAI**: MEDIUM — consumer threat via X distribution, limited enterprise threat

### Meta AI (LLaMA)
- **Founded**: 2013 (FAIR) | **HQ**: Menlo Park
- **Key products**: LLaMA models (open-weight), Meta AI assistant (across Facebook, Instagram, WhatsApp), Llama API
- **Latest models**: LLaMA 4 (Scout, Maverick)
- **Positioning**: Open-source leadership. Making frontier models free pressures everyone's pricing. Consumer reach via social apps.
- **Strengths**: Open-source community (1B+ model downloads), massive consumer distribution (3B+ social media users), AMD partnership for cost-efficient inference, research depth
- **Weaknesses**: No standalone consumer AI product with traction, open-source models cannibalize potential API revenue, enterprise offering still nascent
- **Key people to monitor**: Mark Zuckerberg, Yann LeCun, Ahmad Al-Dahle
- **Twitter accounts**: @ylecun, @AIatMeta
- **Career page**: metacareers.com (filter: AI/ML)
- **Threat level to OpenAI**: HIGH — open-source pricing pressure + social media distribution

## Tier 2 — Rising Challengers (Weekly scan)

### DeepSeek
- **Founded**: 2023 | **HQ**: Hangzhou, China
- **Key products**: DeepSeek V3, DeepSeek R1 (reasoning model), DeepSeek API
- **Positioning**: High-performance models at a fraction of US competitor costs. Open-weight.
- **Why we watch**: If R2 delivers on rumors, it could intensify pricing pressure on OpenAI's API tier. Cost-efficiency narrative is compelling to developers.
- **Last notable signal**: R1 release shook the market. R2 rumored.

### Mistral AI
- **Founded**: 2023 | **HQ**: Paris, France
- **Key products**: Mistral Large, Mistral Medium, Le Chat (consumer), Mistral API
- **Positioning**: European AI champion. GDPR-compliance as differentiator. Open-weight models.
- **Why we watch**: European enterprise pipeline growing. Regulatory advantage in EU markets.
- **Last notable signal**: Quiet recent weeks. Enterprise traction reportedly growing.

### Cohere
- **Founded**: 2019 | **HQ**: Toronto, Canada
- **Key products**: Command R+, Embed, Rerank, RAG-focused enterprise platform
- **Positioning**: Enterprise-focused RAG and search. Not trying to win consumer — going deep on enterprise data workflows.
- **Why we watch**: Could capture enterprise segments where OpenAI's general-purpose API is overkill.

## Tier 3 — Future Tech & Adjacent (Monthly scan)

### World Models / Video Understanding
- **Key players**: Runway, Pika, Google (Veo), Meta (internal research)
- **Why we watch**: Next frontier after text/image. Whoever leads world models may redefine what "AI" means to consumers and enterprises.

### Robotics-AI Convergence
- **Key players**: Figure AI, 1X Technologies, Boston Dynamics, Tesla (Optimus)
- **Why we watch**: Physical AI is a long-term bet. OpenAI has research interest here.

### Agentic Frameworks
- **Key players**: LangChain/LangGraph, CrewAI, AutoGen, Anthropic (tool use)
- **Why we watch**: The winning agent framework determines which LLM provider captures the agent workflow market. OpenAI's function calling vs. Anthropic's tool use is a key battleground.
