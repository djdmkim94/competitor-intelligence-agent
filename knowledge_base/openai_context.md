# OpenAI — Internal Company Context

> This file provides the agent with OpenAI's strategic context so it can evaluate competitive signals through the right lens. Update this file when OpenAI's strategy shifts.

## Company Overview

OpenAI is the leading commercial AI company, founded in 2015, headquartered in San Francisco. The company operates across consumer, enterprise, and developer markets with a multi-layered business model spanning freemium subscriptions, enterprise licensing, and API usage-based revenue.

## Product Lines

### ChatGPT (Consumer)
- **What it is**: Conversational AI product available via web, mobile, and desktop
- **Target users**: General consumers, knowledge workers, students, creators
- **Revenue model**: Freemium (free tier) + ChatGPT Plus ($20/mo) + ChatGPT Pro ($200/mo)
- **Key differentiators**: Largest user base, brand recognition, multimodal (text, image, voice, video), GPT Store/plugins ecosystem
- **Strategic priority**: User retention, daily active usage, expanding into productivity workflows
- **Internal stakeholder**: Product Marketing Managers (PMMs)

### Codex (Enterprise/Prosumer)
- **What it is**: AI-powered coding assistant for developers and engineering teams
- **Target users**: Software developers, engineering teams, enterprises
- **Revenue model**: Subscription tiers for individuals and teams
- **Key differentiators**: Deep IDE integration, multi-file context understanding, enterprise security/compliance
- **Strategic priority**: Enterprise adoption, competing with GitHub Copilot and emerging tools (Cursor, Claude Code)
- **Internal stakeholder**: Product Managers (PMs)

### API & Platform (Developer)
- **What it is**: API access to OpenAI's model family (GPT-4o, o1, o3, etc.) for developers building AI applications
- **Target users**: Developers, startups, enterprises building on top of OpenAI models
- **Revenue model**: Usage-based (per-token pricing)
- **Key differentiators**: Most widely adopted AI API, extensive documentation, function calling/tool use, fine-tuning capabilities
- **Strategic priority**: Developer ecosystem lock-in, maintaining pricing competitiveness, model performance leadership
- **Internal stakeholder**: Business Development / Partnerships

## Strategic Priorities (Current)

1. **Retain consumer dominance** — ChatGPT's moat is brand + habit. Competitors are catching up on capability; retention depends on UX and workflow integration.
2. **Win enterprise coding** — The AI coding assistant market is fragmenting (Copilot, Cursor, Claude Code, Gemini Code Assist). Codex needs to differentiate on enterprise features (security, compliance, multi-repo context).
3. **Defend API market share** — Open-source models (LLaMA, Mistral, DeepSeek) and competitive APIs (Claude, Gemini) are eroding pricing power. Must maintain performance leadership while managing cost.
4. **Advance model capabilities** — Reasoning (o-series), multimodal, agents. These are table-stakes but also the long-term competitive moat.

## Key Metrics to Watch
- ChatGPT DAU/MAU ratio (engagement depth)
- API revenue growth vs. competitors
- Enterprise Codex seat count
- Developer NPS / satisfaction scores
- Model benchmark rankings (MMLU, HumanEval, SWE-Bench, GPQA)
