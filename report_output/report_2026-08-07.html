First Covered TodayMeta — Muse Code beta launched August 5–6: Terminal-Bench 82.9%, $0.10/$0.20 contributor-tier pricing, 1M context, macOS/Linux CLI

Meta Superintelligence Labs released Muse Code in public beta August 5 (Zuckerberg announced on X that evening; Meta AI blog posted August 6). Powered by Muse Spark 1.2. Full profile: 1M context window; Terminal-Bench 2.1 score of 82.9% (above Codex GPT-5.6 Terra: 81.8%; below Claude Code Opus 5: 86.7%); persistent sub-agents with crash-safe event log (resumes exactly where execution stopped after any failure); parallel worktree isolation for concurrent tasks without branch conflicts; CLI only — macOS and Linux (no Windows, no web UI, no IDE plugin).

Meta commits standard-tier prompts are NOT used for training. Available on OpenRouter day one. Rate limits: 3,000 req/min, 4M tokens/min per team.

For Codex PMs: The contributor-tier pricing ($0.10/$0.20) is the sharpest new pricing point in the terminal coding market. At $0.10 input, it undercuts GPT-5.6 Luna ($0.20), Gemini 3.6 Flash ($1.50), DeepSeek V4-Flash ($0.14 off-peak), and every major closed-source API — the only cheaper options are open-weight self-hosted models. For individual developers and startups willing to share data, Muse Code offers near-free frontier-adjacent coding. Codex's moat against Muse Code: the data-sharing opt-in is a non-starter for enterprise compliance requirements. Publish this as an explicit enterprise data-governance differentiation. Async-cloud-sandbox architecture (Codex's niche) is also fundamentally different — Muse Code is synchronous terminal like Claude Code.
