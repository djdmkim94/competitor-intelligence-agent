New — Oct 1

Anthropic — Claude Mods (v2.1.287): TypeScript platform layer transforms Claude Code into customizable developer platform

Claude Code v2.1.287 ships Mods: TypeScript functions that hook into Claude Code's internals. Four hook types: (1) Prompt rewriting — intercept before it reaches the model; (2) Tool call interception — block, rewrite, or retry any tool call; (3) Permission control — approve/deny permission requests in code; (4) Secret redaction — remove secrets from tool output before Claude reads it. Mods ship inside plugins (installed via /plugin). Open-source awesome-claude-mods repo forming on Day 2. Security note: not sandboxed; runs with full machine access.

For Codex PMs: (a) No Cursor equivalent — Cursor's rule system is static text, not code-layer hooks; this creates a structural differentiation where enterprise developers build compliance controls and custom approval workflows natively in Claude Code; (b) The secret redaction hook is the single feature most likely to resolve enterprise procurement objections about secrets in AI coding contexts; (c) The open-source mod ecosystem is a developer flywheel signal — community compliance templates accelerate enterprise adoption; (d) Track whether any Claude Mods authors target Codex feature parity.
