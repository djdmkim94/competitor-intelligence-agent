## 2. ChatGPT Intelligence (PMM Lens)

### Competitor Messaging & Positioning

**Anthropic** — Claude's paid subscriber growth is "skyrocketing" per TechCrunch analysis of billions of anonymized credit card transactions. The growth was driven by three converging forces: (1) Super Bowl ads mocking ChatGPT for showing ads, (2) the Pentagon refusal generating massive brand goodwill, and (3) Claude Code's surging popularity. However, Claude remains "a long way behind ChatGPT" in total paid subscribers, and OpenAI is still gaining new subscribers at a rapid rate. ([TechCrunch](https://techcrunch.com/2026/03/28/anthropics-claude-popularity-with-paying-consumers-is-skyrocketing/))

**Anthropic** — Facing acute capacity constraints due to demand surge. Usage limits reduced during peak hours (5am–11am PT weekdays) for Free/Pro/Max users. Approximately 7% of users experienced stricter daily limits. Users "run through their five-hour session limits much faster." This is simultaneously a threat (they're growing fast) and an opportunity (frustrated Claude users may return to ChatGPT). ([The Register](https://www.theregister.com/2026/03/26/anthropic_tweaks_usage_limits/), [PCWorld](https://www.pcworld.com/article/3100787/anthropic-confirms-its-been-adjusting-claude-usage-limits.html), [PYMNTS](https://www.pymnts.com/artificial-intelligence-2/2026/ai-usage-limits-are-becoming-the-new-reality-for-consumers/))

Personal Intelligence now free for all US users. Lyria 3 Pro music generation (up to 3-minute tracks) launched for subscribers. ([Tech-Insider](https://tech-insider.org/google-gemini-750-million-users-march-2026-updates/), [Google Blog](https://blog.google/innovation-and-ai/products/gemini-app/gemini-drop-updates-march-2026/))

- The Sora shutdown narrative needs aggressive reframing. "We're reallocating compute to what matters" must be the story, not "we killed our video product and lost Disney."
- xAI's key video team departures (Zhang + Liu) create a window where no competitor has a strong consumer video generation offering. If video remains strategically important, this vacuum won't last.

## 3. Codex Intelligence (PM Lens)

### Feature Launches & Competitive Moves

**Anthropic** — Claude Code is now at $2.5B annualized revenue, more than doubling since January 2026. The product added computer use (point, click, navigate without setup), bare mode for scripted calls, and Claude Code Channels (Telegram/Discord messaging). Persistent agent threads (Cowork) rolling out on Pro/Max plans. MCP hit 97M monthly SDK downloads. ([Bloomberg](https://www.bloomberg.com/news/articles/2026-03-03/anthropic-nears-20-billion-revenue-run-rate-amid-pentagon-feud), [Releasebot](https://releasebot.io/updates/anthropic/claude-code))

**NVIDIA** — Launched Nemotron 3 Super, a 120B-parameter open-weight model (12B active) specifically designed for agentic reasoning. Uses hybrid Mamba-Transformer MoE architecture with 1M-token context window. Scores 85.6% on PinchBench (best open model). Already integrated into CodeRabbit, Factory, and Greptile. This gives agentic coding tools a powerful open-source backbone that doesn't depend on any frontier lab's API. ([NVIDIA Newsroom](https://nvidianews.nvidia.com/news/nvidia-debuts-nemotron-3-family-of-open-models), [MarkTechPost](https://www.marktechpost.com/2026/03/11/nvidia-releases-nemotron-3-super-a-120b-parameter-open-source-hybrid-mamba-attention-moe-model-delivering-5x-higher-throughput-for-agentic-ai/))

**Industry-wide** — The "agent" race is fully underway. Every major coding tool has shipped or is shipping agent capabilities: GitHub Copilot Agent Mode, Cursor Background Agents, Windsurf Cascade, Claude Code Cowork. The competitive axis has shifted from "AI autocomplete" to "autonomous software engineer." Codex's positioning as a cloud-based autonomous agent is aligned with this trend, but Claude Code's terminal-native approach and SWE-bench lead remain advantages. ([NxCode](https://www.nxcode.io/resources/news/openai-codex-vs-cursor-vs-claude-code-ai-coding-tools-2026))

### Benchmark Comparisons

| Tool | Architecture | Key Metric | Pricing |
|---|---|---|---|
| Claude Code (Opus 4.6) | Terminal-native agent | ~80.8% SWE-Bench | $20 (Pro) / $100 (Max) / $200 (Max 20x) |
| Codex (Internal) | Cloud-based autonomous agent | 2-4x fewer tokens/task | Bundled with ChatGPT Plus/Pro |
| Cursor | AI-native IDE | Background Agents shipped | $60 (Pro+) / $200 (Ultra) |
| GitHub Copilot | IDE extension + Agent Mode | 4.7M paid subscribers | $10-19/mo individual |
| Nemotron 3 Super | Open-weight backbone | 85.6% PinchBench | Free (open-weight) |

**Key delta from last week**: Codex's token efficiency (2-4x fewer tokens per task) is a real cost advantage for enterprise. Claude Code's revenue growth ($2.5B ARR) proves the market values raw capability over cost efficiency at this stage.
